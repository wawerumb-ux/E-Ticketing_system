# ICT E-Ticketing System

A comprehensive internal ticketing system for ICT department support.

## Features

- Dashboard with real-time statistics
- Create, view, update, and delete tickets
- Ticket filtering and search
- User management
- Priority and status tracking
- Responsive design

## Technology Stack

- **Backend**: Python Flask
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL (XAMPP) / PostgreSQL (Supabase)
- **Deployment**: Local (XAMPP) or Cloud (Render/Supabase)

## Installation

### Local Development (XAMPP)

1. Install XAMPP and start MySQL
2. Create database using the SQL script in `backend/database/init.sql`
3. Install Python dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
