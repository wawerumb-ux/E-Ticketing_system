SLA Timers & System Settings

Response/resolution windows (minutes) are applied when a ticket is created or its priority changes. Existing tickets are not retroactively adjusted.

Ticket Priority Rules

New tickets are assigned an initial priority by evaluating these rules top to bottom. The first match wins unless the rule is set to keep evaluating. You can tune a rule's priority, order, and values — not its shape, which is developer-controlled. When no rule matches, the fallback priority is used. Existing tickets are not revisited.
